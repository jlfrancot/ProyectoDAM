# Proyecto DAM

**Proyecto Intermodular DAM 2026-2027**

**Nombre del proyecto:** ImportadorApuntes

Aplicación Java para transformar archivos contables de diferentes ERP y prepararlos para su importación en a3ERP.

## Trabajos realizados

- 1.1 - Análisis del sector
- 1.2 - Estudio de mercado (DAFO)
- 1.3 - Innovación, dificultad e investigación
- 1.4 - Ayudas y subvenciones
